# Bot Panel

Mod do Minecrafta (Fabric 1.21.4, tylko klient) - panel do zarządzania botami.

## Instalacja
1. Zainstaluj Minecraft 1.21.4 z [Fabric Loader](https://fabricmc.net/use/).
2. Pobierz [Fabric API](https://modrinth.com/mod/fabric-api) i wrzuć do folderu `mods`.
3. Pobierz `botpanel-*.jar` z zakładki **Releases** i wrzuć do folderu `mods`.

## Budowanie
Wymagane JDK 21:

    gradle build

Gotowy plik jar znajdziesz w `build/libs/`.
